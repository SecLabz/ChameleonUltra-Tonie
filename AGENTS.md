# ChameleonUltra-Tonie

- Ultra-only SLIX-L emulation with an offline USB web interface; no BLE or reader mode.
- Write source comments, UI, and documentation in English.
- Build: `make app`. Local tests: `make test`. Hardware tests require explicit authorization.
- Preserve RF timing, the library across updates, and upstream notices.
- Before remote firmware changes, verify recovery and keep a working fallback. Preserve the bootloader.
- See [README.md](README.md) and [docs/development.md](docs/development.md) for project and technical details.
